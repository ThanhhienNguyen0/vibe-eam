# ViewpointRule Diagram

Source: [viewpoint-rule-diagram.mmd](./viewpoint-rule-diagram.mmd)

This diagram explains the stakeholder-specific views in the Rule Builder.

Key distinction:

- `Stakeholder` remains a model element. It can appear as a node in diagrams.
- `Viewpoint` is a role-specific filter. It decides which types and rules are visible or allowed for a stakeholder role.
- `ViewpointRule` contains the concrete allowed and required component types, connection types and connection rules.
