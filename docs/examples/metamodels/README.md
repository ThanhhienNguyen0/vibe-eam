# Metamodel JSON Examples

The canonical default EAM metamodel JSON is maintained at:

```text
backend/src/data/default-metamodel.json
```

It can also be downloaded from the Metamodel UI via `Download default EAM metamodel`.

The file is intentionally not duplicated here to avoid divergent examples. Format details are documented in [../../METAMODEL_JSON_FORMAT.md](../../METAMODEL_JSON_FORMAT.md).
